# 인계문서 — 40차 (v0.40, 2026-11-18)

## 요청 (사용자)
악보에 괄호가 들어간 코드(어떤 악기만 치거나 안 쳐도 되는 코드)를 코드로 다루기. `(Am)`, `(A Dm)` 형태, 괄호는 연한 색, 코드 안쪽 괄호도 함께.

## 한 일 (설계문서 50장)
- 괄호 코드 이조·검사·이름 보정·표시(화면·연주·PDF)·키보드 입력(⇧9 ( … ⇧0 ))·도움말 한 줄.
- `Am(add9)`류 코드 안쪽 괄호를 코드로 인정.
- 서비스워커 캐시 v3.

## 시험
- Node: `(Am)`·`(A Dm)`·`(A`·`Dm)`·`Am(add9)`·`(G/B)` 이조, isChord, 보정, 편집기 검사 경고 없음.
- Playwright: 괄호 코드 화면 렌더(연한 괄호), PDF 생성 1쪽 오류 0.
- 키보드 토큰 시뮬레이션(`(` A m `)`). 실제 편집 화면에서 키를 눌러 본 시험은 못 함 → 실기기 확인 필요.

## 사용자 확인 대기
1. 편집 화면에서 ⇧9로 `(`, ⇧0으로 `)`가 입력되는지, 한글 입력 상태·아이패드 키보드에서도 되는지.
2. 같은 괄호 안에 코드 둘: `(` A 그리고 ⇧D, m, ⇧0 → `(A Dm)`.
3. 괄호 연하기(투명도 .45)·크기가 보기 좋은지. 오래 읽어 보고 조정 가능.
4. 편집 화면의 코드 칩(`tk`)·팔레트는 아직 일반 글자(괄호만 그대로 보임).
