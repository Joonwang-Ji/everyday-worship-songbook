## 한 일 (설계문서 51장) — 1~3번
- 덧붙임 아랫첨자 / ♯♭ 윗첨자 (화면·PDF).
- 소문자 코드 `[c]`·`[em]`·`[(a dm)]`를 읽을 때 대문자로 보정(이조·표시·검사). 코드 모양이 아닌 낱말은 그대로.
- "원래대로"를 −의 왼쪽 고정 자리에 두고 변경 없을 땐 비활성.
- 서비스워커 캐시 v4.

## 시험
- Node: `[c]`→C, `[em]`→Em, `[(a dm)]`→(A Dm), `[bridge]`·`[?]` 그대로, `c` 이조(+2)→D, 편집기 검사 경고 없음.
- Playwright: Csus4·F♯m7♭5·B♭maj7·D/F♯·(A Dm)·Cadd9/E 렌더 스크린샷 확인(아래 첨자·위 첨자).
- 연주 모드 버튼·PDF 실제 화면은 못 봄 → 실기기 확인 필요.

## 사용자 확인 대기
1. 아랫첨자 크기·깊이, ♯♭ 위치가 보기 좋은지(PDF 포함).
2. 소문자 c: 어떤 상황에서 안 됐는지(키보드로 칠 때인지, 본문에 직접 적을 때인지) — 키보드 입력 경로는 코드상 원래 소문자를 받음. 계속 안 되면 기기·입력 방식 알려 주세요.
3. 연주 모드 원래대로 버튼 위치(− 왼쪽)가 편한지.
