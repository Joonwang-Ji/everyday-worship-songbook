# 인계문서 — 45차 (v0.45, 2026-11-19)

## 요청 (사용자)
해외에서 통신이 안 될 때를 대비해 오프라인 저장 상한을 1000장으로, "전체 오프라인 저장" 버튼 추가, PDF도 포함.

## 한 일 (설계문서 60장)
- `sw.js`: 악보 파일 저장 상한 150 → 1000, 캐시 v15.
- 더보기에 `⬇ 전체 오프라인 저장` 카드: 모든 곡·악보(이미지·PDF) 일괄 저장, 진행률 표시, 저장 장수·사용량 표시, 저장 공간 보호 요청.
- 콘티 "오프라인 준비"도 PDF 포함.

## 시험
- Node 문법 확인(`app.js`·`sw.js`). 실제 서버·서비스워커·오프라인 동작은 이 환경에서 **확인 못 함**.

## 사용자 확인 대기 (실기기, 홈 화면에 추가한 앱으로)
1. 더보기 → `전체 곡 저장하기`(와이파이) → 진행률이 오르고 끝나면 "n곡 저장" 알림이 뜨는지.
2. 비행기 모드로 앱을 열어 저장한 곡(이미지·PDF·코드)이 열리는지. 필기도 되는지.
3. 오프라인에서 앱을 처음 열었을 때 로그인·팀 입장이 막히지 않는지(**해외 출발 전 꼭 시험**).
4. 곡이 매우 많을 때 시간·용량(MB 표시)이 괜찮은지.

## 알아 둘 것
- 오프라인에서 곡 목록·검색은 안 된다(저장 안 함). 콘티·이미 열어 본 곡 주소로 연다 → 필요하면 다음 차수에서 곡 목록도 저장.
- 로그아웃하면 저장본이 모두 지워진다.
