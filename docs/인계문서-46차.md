# 인계문서 — 46차 (v0.46, 2026-11-19)

## 요청 (사용자)
관리자 비번으로 들어가면 팀 코드·팀장 코드 없이 모든 팀에 들어가 관리할 수 있게.

## 한 일 (설계문서 61장)
- 서버 `POST /api/admin/teams/:id/enter`(관리자 전용): 팀원+팀장 열쇠 발급.
- 팀 가입 화면: 관리자면 팀 목록 버튼, 아니면 "관리자 PIN으로 입장". 앱 관리 팀 카드에 `이 팀으로 입장 (팀장)`.

## 시험
- Node 문법 확인(`app.js`, API). 실제 서버·화면 동작은 이 환경에서 **확인 못 함**.

## 사용자 확인 대기
1. 새 기기: 접속암호 → (팀 가입 화면) `관리자 PIN으로 입장` → PIN → 팀 버튼을 누르면 바로 콘티 화면, 팀장 기능(콘티 편집)이 되는지.
2. 앱 관리 → 팀 목록 → `이 팀으로 입장 (팀장)`.
3. 팀 전환 칩으로 여러 팀을 오가는지.
