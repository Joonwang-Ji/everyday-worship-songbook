# 인계문서 49차 — 키 필터 주변 키 포함

## 요청
찬송가 Ab 등을 실제로는 G·A로 연주하므로, 키 필터에 주변 키도 포함. 기본 켜짐(곡이 적어서).

## 한 일
- `public/songfilter.js`: `keyNear`(±반음, 장·단조 구분, B↔C 이어짐), 필터 상태 `near`(기본 true), `matches`·`toggle`·`chipsHTML`(`± 주변 키 포함` 칩)·`summary`(`G ±`)·주소(`near=0`일 때만 저장).
- 곡 목록과 콘티 곡 추가 창이 같은 코드를 써서 둘 다 적용된다. `app.js` 수정 없음.
- 설계문서 63장, 결정기록 추가.

## 시험
- Node 단위 확인: G→F#·Gb·G·Ab 포함, A·F·Gm 제외 / C→B·Db / Am→G#m·Bbm / 끄면 정확히만 / 주소 왕복(`near=0`, 없으면 켜짐) / 기본 상태가 "필터 중"으로 세어지지 않음.
- 폰·아이패드 화면 확인은 못 함.

## 사용자 확인 대기
