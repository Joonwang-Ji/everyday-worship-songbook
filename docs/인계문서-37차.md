# 인계문서 — 37차 (v0.37, 2026-11-18)

## 요청 (사용자)
35차 한 줄 보기에서 악보↔코드 전환 버튼이 사라져 아쉽다 → 상단 줄을 늘리지 않고 방법 찾기. 오른쪽 위 모서리(오른손잡이, 이미지 악보 아래·왼쪽은 악보 영역일 수 있음). "자세히"는 더 나오는 정보가 없으니 한 줄이 기본.

## 한 일 (설계문서 47장)
- 악보 오른쪽 위 모서리에 `⇄ 이미지/코드`, `⇄ 송폼순/악보순` 떠 있는 버튼. 해당 없는 곡(둘 중 하나만 있는 곡)에는 안 나옴.
- "연주 전 조정" 창에서 그 버튼 제거(키·카포만). "상단 정보 한 줄/자세히" 설정 삭제(항상 한 줄).

## 시험 (로컬 정적 서버 + Playwright, API 가짜 응답)
- 390×844, 1024×1366: 둘 다 있는 곡에서 버튼 2개(위치 오른쪽 8px·위 6px), 누르면 이미지↔코드·송폼순↔악보순 전환, 코드만/이미지만 있는 곡은 버튼 없음, 설정 창에 상단 정보 줄 없음, 조정 창에 전환 버튼 없음, 페이지 오류 0.
- 미시험: 실기기, Apple Pencil 필기 중 모서리 근처, 가로 폰(높이 520 이하).

## 사용자 확인 대기
1. 브랜치를 main에 병합 → 연주 모드에서 모서리 버튼 위치·크기·가림 정도 확인(코드 악보 첫 줄 오른쪽 끝 코드가 가려지는지).
2. 거슬리면: 크기·투명도 조정, 또는 3초 뒤 흐려지게 하는 방법 가능.
