# 인계문서 — 44차 (v0.44, 2026-11-19)

## 요청 (사용자)
인계문서의 다음 후보인 곡별 "보완 필요" 표시(관리자·팀장 전용). 설계 3가지(종류·저장·보이는 곳)를 모두 추천안으로 확정(설계문서 59장).

## 한 일
- 서버: `songs.needs_work` 칸, `PUT /api/songs/:id/needs`, 목록·상세는 관리자·팀장에게만 값을 보냄.
- 화면: 곡 보기 위 `🚩 보완 필요` 선택칸, 곡 목록 배지, 필터 칩 `🚩 보완 필요 표시`. 서비스워커 캐시 v14.

## 시험
- Node: `needsBadge`·`matches(fmt=needs)`·`fromQuery`·`badgesHTML` 확인, 서버·`app.js` 문법 확인.
- 실제 서버(D1)는 이 환경에 wrangler가 없어 **통합 확인 못 함**.

## 사용자 확인 대기 (실기기)
1. 팀장으로 곡 보기 → `🚩 보완 필요`에서 종류를 고르면 "표시했어요"가 뜨는지, 곡 목록에 배지가 보이는지.
2. 곡 목록 필터 → 악보 → `🚩 보완 필요 표시`로 걸러지는지.
3. 팀원(팀 가입만 한 기기)에서는 선택칸·배지·칩이 안 보이는지.
4. 이 표시를 바꿔도 곡 "수정 이력"·수정일이 안 바뀌는지.
- (이전 대기) 43차 후속 1·2: 이미지·코드 필기 도구 모양 통일, 글자 입력창 위쪽.
