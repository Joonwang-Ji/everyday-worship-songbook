# 인계문서 51차 — 가사 복사 빈칸 · 송폼 후렴 번호

## 요청
1. 코드 자리 맞추려고 넣은 빈칸 때문에 가사 복사가 "사랑 으로"처럼 됨.
2. 후렴이 여러 개(C1·C2·C3)인데 송폼 만들기에는 C만 있음.

## 한 일
- `songform.js` lyricSections: 코드가 빈칸 위에 있고 앞뒤가 한글이면 빈칸 제거.
- `app.js` 송폼 편집기: 악보에 있는 번호 구간(C2·C3 등)을 버튼으로 추가.
- 설계문서 64장.

## 시험
- Node: "사랑"+" 으로"(코드 위 빈칸) → "사랑으로", "주님 사랑"은 유지. 후렴1·2·3 악보 → 구간 id C·C2·C3.
- 화면 확인은 못 함.

## 사용자 확인 대기
- 빈칸을 넣은 곡의 가사 복사 / 송폼 만들기에서 C2·C3 버튼 확인.
- 코드 없이 넣은 빈칸이나 한글 아닌 글자는 그대로 둠.

## 51차(b) — 빈칸 방식 교체
- 첫 방식(코드가 얹힌 한글 사이 빈칸을 모두 제거)이 원래 띄어쓰기까지 붙여서, 코드용 빈칸만 NBSP로 따로 저장하는 방식으로 교체.
- 이미 넣어 둔 빈칸은 표시가 없어 그대로 두 글자로 복사됨 → 해당 곡은 빈칸을 지우고(␣✕) 다시 넣어야 함.
- 시험: Node(코드용 빈칸 제거, 원래 띄어쓰기 유지, 편집 왕복). 화면 확인 못 함.
