# 인계문서 48차 — 괄호 닫기 입력 고침

## 요청
키보드 코드 입력에서 C 뒤에 괄호 닫기 `)`가 안 들어감.

## 한 일
- 원인: `)`(⇧0)가 "같은 칸에 `(`가 있을 때"만 들어갔다. `(A` / `Dm)`처럼 칸을 나눠 적는 경우(40차 설계)에 뒤 칸에서 `)`를 칠 수 없었다.
- `public/chordedit.js` keyToken: 코드 뒤라면 `(`가 없어도 `)`를 받는다. (`?`·`/` 뒤·이미 닫힌 뒤는 그대로 막음)
- `public/app.js` 도움말 한 줄에 칸 나눠 적는 방법 추가.

## 시험
- Node로 keyToken 확인: C·Dm·C# 뒤 `)` 들어감, `A/`·`?`·`C)` 뒤는 막힘. `Dm)`·`(A` 모두 isChord 통과.
- 실기기(아이패드·맥북 키보드) 확인은 못 함.

## 사용자 확인 대기
- 한 칸에 `(`C`)` 를 쳐도 안 되면 진단(더보기 → 필기 진단)을 켜고 ⇧0을 눌렀을 때 뜨는 `키:` 표시를 알려 주세요.

## 추가 (48차 2)
- 괄호 코드는 안쪽 코드도 연하게(투명도 45%): 화면 `.ch .cg`(chord.js chordHTML), 내보내기 export.js(dim). 칸을 나눈 "(A"·"Dm)"도 같다. 이전엔 괄호 글자만 연했다.
- 코드가 없는 빈칸에서 Backspace = 빈칸 지우기(app.js, 기존 removeSpace 연결). 코드가 있는 칸은 첫 Backspace가 코드를 지우고, 한 번 더 누르면 빈칸을 지운다.
- 시험: node 문법 검사·chordHTML 출력 확인만. 실기기 확인 못 함.

## 추가 (48차 3)
- 코드 안쪽 괄호 A(add2): 코드 뒤에서 ⇧9로 "(" → a d d 2 → ⇧0 로 ")" (안쪽 괄호가 열려 있으면 ⇧0은 안쪽을 닫음). 괄호 안에서 # · b · 숫자 · a d s u m j i g 도 받음(A(#5)·A(b9)). 바깥 괄호 닫힘 판정은 peelGroup 기준. chordedit.js keyToken.
- 빈칸 넣기(스페이스바·"␣ 빈칸" 버튼)는 선택한 글자의 오른편에 생기고, 선택은 새 빈칸으로 옮긴다(tabedit.js insertSpace). 줄 끝 칸은 전과 같다.
- 시험: node로 키 순서·insertSpace 확인. 실기기 확인 못 함.
