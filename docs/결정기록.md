# 결정기록 (압축본, 2026-11-16 기준)

claude.ai 프로젝트에서 33차까지 진행하며 정한 것들. 진행 상황이 아니라 "무엇을 왜 정했는지"만 적음. 자세한 경위는 인계문서-N차.md 참고.

## 앱 기본
- 이름: Everyday Worship Songbook (처음엔 Score였다가 변경)
- 배포: GitHub 저장소 → Cloudflare Pages, 이미지·PDF 악보는 Cloudflare R2. 접속암호 로그인.
- 차수별로 구현, 사용자가 실기기(아이폰13미니, 아이패드미니5·에어M2, 맥북)에서 확인.

## 악보·곡 정보
- 코드 악보와 이미지·PDF 악보 둘 다 지원. 이미지 악보도 콘티에서 키를 계산해 기록·수정 가능.
- 찬양 주제: 자유 태그 + 추천 칩, 한 곡에 여러 개, 추천 목록 편집은 관리자만. 빠르기(빠른곡/느린곡)·절기도 함께 분류. 성탄은 주제가 아니라 절기. 절기에 성령강림절 포함.
- 박자(4/4 등)는 키 배지 오른쪽에 노출, 한 곡에 여러 박자 가능. 원키와 팀 키가 다르면 팀 키로 보이고 원키 병기. 키 필터·정렬은 팀 키 기준.
- 키 필터: 원래 키 기준 다중 선택, 키순 정렬(장조 C→B, 다음 단조, 키 없음 맨 끝). 필터 상태는 주소에 저장.
- 코드 악보 입력: ChordPro 문법 대신 버튼 입력(구간·코드 버튼줄, 임시저장, 저장 전 점검, 탭 편집기). 숫자(도수) 입력은 불필요.

## 팀·콘티·연주
- 악보 편집은 관리자·허용된 팀장만. 초대코드는 관리자 화면에서 재발급. 팀별 기본 키 저장. 콘티 항목마다 코드/이미지 악보 선택.
- 복수 팀은 팀 전환 방식.
- 연주 모드: 좌우 스와이프로 이전·다음 곡, 상단에 송폼·메모, 곡 하나씩 임시 키 −/+(나가면 콘티 키로 복귀, 이미지·PDF는 키 표시만 변경), 카포 설정.
- 송폼: 버튼으로 만들기, 전조 표시(반음 +n과 도착 키 둘 다, 연속 전조 가능, 곡 등록 때도 가능), 표준 이름이 아닌 "그 밖의 구간"도 악보에 이름표로 표시, 송폼 순서 보기에서 구간을 끊지 않고 구간 단위로 다음 단으로.
- UI는 필요한 순간에 필요한 기능이 나타나게 단순화(5.5차 개편).
- 쪽 넘기기(후렴으로 점프)는 효과가 작아 보류.

## 내보내기
- 카톡용 텍스트는 간단형. PDF/이미지에 "교회 내부 사용 전용" 문구는 넣지 않음.
- 콘티 가사 복사 3가지 모양(제목+가사 / 송폼 순서대로 / 가사만). 한국어 가사는 띄어쓰기를 뺀 글자 수로 코드 위치를 센다. 영어 가사는 기존 방식.

## 필기
- 이미지 악보 위 개인 필기(펜·형광펜·지우개·되돌리기·글자 메모), 개인 보관함 코드로 기기 간 동기화.
- 사용 환경: 아이패드미니5+애플펜슬1세대(호버 없음), 아이패드에어M2(지우개 호버 선호), 아이폰(손가락).
- 앞으로: 코드 악보 줄 앵커 필기(개인) → 팀장이 고른 필기를 팀원이 읽기 전용으로 공유. 반복 구간도 회차마다 필기가 달라질 수 있어야 함(기본은 이 회차만, 모든 회차 보기 선택 가능). 코드 악보에도 필기하는 것이 최종 목표.
- 콘티용 필기 포함.

## 이미지 → 코드 변환 (저작권 설계, 가장 중요)
- 앱 안 자동 변환(AI)은 하지 않음(API·추가비용 싫음). Claude 앱에서 복사→붙여넣기로 변환.
- 2단계 방식: ① 가사만 뽑기 → ② 사람이 다듬기 → ③ 그 가사 위에 코드만 입히기.
- 사용자가 올린 악보에 인쇄된 내용만 옮긴다. 기억·웹·다른 곡에서 채우지 않고, 안 보이면 `?`.
- 앱에 외부 악보·가사 가져오기/URL 불러오기 기능 금지. 외부 사이트는 검색 링크로만. 공개 검색·배포 금지.
- 악보에 없는 구간 표시(간주, 아웃트로, 태그 등)를 임의로 쓰지 않는다.
- **코드 입히기 기준** (앱에서 직접 고친 최종 버전이 정답):
  1. 코드는 단어 앞이 아니라 악보에서 그 코드가 놓인 음표의 음절 바로 앞에 넣는다 (예: 높[A]으신, 어두[B]운).
  2. 줄 끝 마무리 코드(예: 오셨[E]네)를 빠뜨리지 않고, 줄 첫머리에 임의로 [E]를 넣지 않는다.
  3. 2절 이후 줄은 1절의 코드 위치를 복사하지 말고 그 줄 가사의 음절에 맞춰 위치를 다시 찾는다.
  4. 후렴 직전 줄처럼 마지막 글자 뒤에서 코드가 바뀌면 끝에 한 번 더 넣는다 (예: 오셨[E]네[E]).
  5. `{soc}/{eoc}`, `{ref: C}` 같은 구조 정리는 앱의 후처리이므로 변환 결과에 넣지 않는다.

## 작업 방식 (Claude Code 이전 후)
- Claude Code는 웹 방식으로 사용(폰·아이패드에서도 쓰기 위해). 작업용 브랜치(예: work/34차)에만 푸시하고, main 푸시·병합은 사용자가 GitHub에서 한다. 차수마다 커밋 하나로 묶기(여러 번 커밋하기 번거로움).
- 새 세션은 설계문서 10장·36·36-b장·43장과 최신 인계문서를 먼저 읽는다.
- 사용자는 한국어, 단계별 안내를 원함. 고치기 전에 먼저 말할 것.

## 코드 악보 필기 (43차)
- 필기는 전체 화면 필기 창에서: 악보 전체가 한 화면에, 도구 줄은 위쪽, 확대·이동은 변환 하나로만(스크롤·레이아웃을 건드리지 않음). 곡 보기·연주 모드 공통.
- 송폼을 바꿔도 "이 회차만" 필기가 따라가도록 앞 구간 이름을 함께 저장, 못 찾으면 정리 안내, 송폼 저장 때 영향 알림(설계문서 58장).

- 키 필터는 기본으로 주변 키(±반음)까지 포함(49차). 끄면 정확한 키만. 곡이 적어 기본 켜짐으로 사용자 결정. 설계문서 63장.
