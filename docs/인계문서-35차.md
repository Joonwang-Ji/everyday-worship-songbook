## 요청 (사용자)
상단 정보 때문에 악보가 작아진다 → 한 줄로 줄이되 되돌릴 수 있게. 연주 중 필요한 정보는 손 안 쓰고 보여야 함. 연주 중 키 변경 없음. 추천 기능 중 3(BPM 표시)·4(콘티 흐름 점검 줄)·5(콘티 요약 카톡 공유)를 하기로 함 → 35차는 상단 한 줄 + BPM, 36차에 4·5.

## 한 일 (설계문서 45장)
- 연주 모드 ⚙에 "상단 정보 한 줄/자세히"(기본 한 줄). 한 줄은 제목 줄에 키·BPM·박자, 아래에 송폼·메모·다음 곡 상시 표시. 키·카포·악보 전환·송폼 순서 전환은 키 칩(▾)을 누르면 열리는 "연주 전 조정" 창으로.
- BPM(`♩72`) 표시 추가(두 모드). 서버 변경 없음.

## 시험 (로컬 정적 서버 + Playwright, API는 가짜 응답)
- 상단 높이/악보 칸 높이(자세히 → 한 줄): 폰 390×844 174→87px / 670→757px(+13%), 아이패드 세로 1024×1366 112→70 / 1255→1296, 가로 1366×1024 86→70 / 938→954.
- 키 칩 → 창 열림, + 누르면 키 바뀌고 창 유지, 닫기, 설정에서 자세히로 전환하면 예전 버튼이 위로 돌아옴. 페이지 오류 0.
- 미시험: 실제 아이폰·아이패드, 이미지 악보 곡, 곡 사이 넘김 중 창 상태, 긴 송폼·메모에서의 줄 수.
